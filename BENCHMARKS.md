# BENCHMARKS

All evaluation, testing, and benchmarking scripts for MAPF-SNN / LSM-MAPF.
Quick reference for what to run and what you get back.

---

## Prerequisites

```bash
# Checkpoint locations (used by most scripts)
checkpoints/lsm/phase1_cortex.pt        # LIF network — Phase 1 (supervised)
checkpoints/eval_ablation/swarm1.pt     # LIF network — ablation-ready
checkpoints/hh_lts/swarm_hh.pt         # HH-LTS network (generated by test_hh_smoke.py)

# Dataset (regenerate if missing)
cd data_generation && python main_data.py   # uses LaCAM, ~2 min

# LaCAM binary (needed by eval_benchmark.py and data generation)
cmake -B solvers/lacam0/build solvers/lacam0 -DCMAKE_BUILD_TYPE=Release
make -C solvers/lacam0/build -j$(nproc)
```

## Scripts

### `eval_benchmark.py` — Multi-algorithm head-to-head

The main benchmark. Runs LSM-MAPF (SNN), PIBT, CBS, and LaCAM* on identical random maps and reports hardware-independent compute metrics alongside MAPF quality metrics.

```bash
python eval_benchmark.py
python eval_benchmark.py --densities 0.05 0.1 0.15 0.2 --n-agents 4 8 16 --episodes 20
python eval_benchmark.py --target-fpga-mhz 200 --num-ticks 10
```

**Key flags**

| Flag | Default | Notes |
|---|---|---|
| `--densities` | `0.1 0.2 0.3` | Obstacle densities to sweep |
| `--n-agents` | `4 8 16` | Agent counts |
| `--episodes` | `20` | Episodes per (density, N) cell |
| `--grid-size` | `32` | Map size (square) |
| `--num-ticks` | `10` | FPGA clock cycles per decision |
| `--target-fpga-mhz` | `100` | For LSM latency estimate |
| `--lsm-checkpoint` | `checkpoints/eval_ablation/swarm1.pt` | |
| `--lacam-bin` | `solvers/lacam0/build/main` | |
| `--out-dir` | `experiments/benchmark` | |

**Outputs** (written to `--out-dir`)

- `results.json` — raw per-(algorithm, density, N) data
- `summary.csv` — flat table
- `csr_vs_density.png` — completion success rate curves
- `latency_vs_nagents.png` — hardware latency scaling
- `hw_muls_per_step.png` — multiplier count comparison

**Hardware metrics explained**

- `est_hw_latency` — FPGA: `(ticks / MHz) × 1000 µs`; CPU solvers: wall-clock ms/step
- `seq_depth` — LSM = 1 (all N agents pipelined); PIBT = N; CBS/LaCAM = O(b^d · N)
- `ALU_profile` — `Adds-Only (0 Multipliers)` for LSM vs `Standard ALU` for others

### `ablation_eval.py` — Module ablation sweep

Tests the full model against three ablated variants across agent counts and obstacle densities. Also generates spike-health diagnostics.

```bash
python ablation_eval.py
python ablation_eval.py --episodes 50 --agent-counts 2,5,10,15,20
python ablation_eval.py --ablations full,no_cpg --checkpoint checkpoints/lsm/phase1_cortex.pt
```

**Ablation variants**

| Variant | What's removed |
|---|---|
| `full` | Nothing — baseline |
| `no_shadow` | Shadow Caster + VETO bridge |
| `no_ghost` | Ghost Antenna (pheromone lookahead) |
| `no_cpg` | CPG oscillator (turn-taking) |

**Key flags**: `--episodes`, `--agent-counts`, `--grid-size`, `--obstacle-density`, `--checkpoint`, `--out-dir`

**Outputs**: per-variant plots, spike rasters, `summary.csv`

### `test_hh_smoke.py` — HH-LTS neuron comparison

Trains a new HH-LTS reservoir from scratch (ridge regression on expert states), then compares it head-to-head against the pre-trained LIF network. Per-episode progress is logged.

```bash
# First run: trains HH, saves checkpoint, evals both
python test_hh_smoke.py --episodes 20

# Faster: fewer training episodes, shorter eval
python test_hh_smoke.py --train-episodes 100 --episodes 5

# Skip retraining (use existing HH checkpoint)
python test_hh_smoke.py --skip-retrain --episodes 20

# Force retrain even if checkpoint exists
python test_hh_smoke.py --retrain --episodes 20

# Only run one variant
python test_hh_smoke.py --hh-only --train-episodes 200
python test_hh_smoke.py --lif-only
```

**Key flags**

| Flag | Default | Notes |
|---|---|---|
| `--train-episodes` | `200` | Expert eps for HH state collection |
| `--hh-i-scale` | `50.0` | μA/cm² per unit input — tune excitability |
| `--hh-checkpoint` | `checkpoints/hh_lts/swarm_hh.pt` | Save/load path |
| `--episodes` | `20` | Eval episodes per variant |
| `--num-ticks` | `10` | Ticks per decision (try 20–40 for HH) |

**What it measures**: CSR (all agents reach goal), ISR (per-agent rate), makespan

### `eval_jitter.py` — Timing jitter robustness

Injects `SpikeJitterBuffer` delays between Observation Mesh and Readout Mesh to measure how robust the SNN is to asynchronous spike timing (simulates FPGA clock skew / noisy sensors).

```bash
python eval_jitter.py
```

No CLI flags. Edit the jitter parameters directly in the script.

**Output**: `jitter_robustness.png` — CSR vs jitter delay curve

---

### `compute_ops.py` — Operations count

Counts exact synaptic accumulations (adds) for SNN and multiply-accumulates (MACs) for dense neural baselines. Reports a unified ops table across all algorithms.

```bash
python compute_ops.py
python compute_ops.py --n-agents 1 2 4 8 16 --episodes 50
```

**Key flags**: `--n-agents`, `--episodes`, `--num-ticks`, `--grid-size`, `--density`, `--checkpoint`

**Output**: printed ops table (no file saved)

---

### `ablation_path_length_compare.py` — CPG vs Ghost path length

Compares average steps-to-goal broken down by which modules were active (CPG only / Ghost only / both / neither). Useful for isolating the contribution of each module to navigation efficiency.

```bash
python ablation_path_length_compare.py
```

No CLI flags. Hardcoded checkpoint (`checkpoints/lsm/phase1_cortex.pt`), grid 20×20, density 0.10, 20 episodes, agent counts `[2, 5, 10, 15, 20]`.

**Output**: printed table only

---

### `agent_avg_steps.py` — Scalability sweep

Sweeps agent count and reports average steps-to-goal per agent, useful for showing O(N) scalability vs search-based methods.

```bash
python agent_avg_steps.py
```

No CLI flags. Hardcoded agent counts `[2, 5, 10, 15, 20]`, grid 20×20, 20 episodes.

**Output**: printed table only

---

### `test_eval_quick.py` — Smoke test for trainer

Verifies the `SwarmTrainer.evaluate()` pipeline doesn't crash. Loads the valid dataset and runs 3 episodes. Not a benchmark — just a sanity check.

```bash
python test_eval_quick.py
```

**Output**: printed pass/fail

## Recommended run order

```
# 1. Generate data (if dataset/ is missing or stale)
cd data_generation && python main_data.py && cd ..

# 2. Train
python train_swarm_lsm.py

# 3. Quick sanity check
python test_eval_quick.py

# 4. Module ablation
python ablation_eval.py --episodes 50

# 5. Multi-algorithm benchmark
python eval_benchmark.py --densities 0.05 0.1 0.2 --n-agents 4 8 16 --episodes 20

# 6. Ops + scalability
python compute_ops.py
python agent_avg_steps.py

# 7. HH-LTS neuron experiment
python test_hh_smoke.py --train-episodes 200 --episodes 20

# 8. Jitter robustness
python eval_jitter.py
```
